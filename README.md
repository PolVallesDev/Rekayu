# Rekayu - Web Para Recordatorios y Anotaciones

Rekayu es una pàgina web diseñada y pensada especialmente para satisfacer las necessidades personales de su creador. Capaz de satisfacer a todas aquellas personas estudiantes y emprendedoras, especialmente aquellas que son ambas cosas, como es el caso del creador de esta web. Como bien se sabe los jovenes estudiantes y/o emprendedores tienen varias tareas/examenes que recordar a parte de ideas/notas que deben apuntar de forma simple y rápida para no olvidarse, Rekayu trata de solucionar esos pequeños detalles centralizando todo en un simple sitio.
